### Featured project

**[ngx-callout](https://github.com/vishaalsharmaa/ngx-callout)**: accessible, themeable callouts (admonitions) for Angular.
Six types (info, warning, error, success, tip, important), zero dependencies, built for Angular 21 with signals and standalone components. MIT licensed.
